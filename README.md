# zxcv

> A minimalist, fast .tool-versions manager.

zxcv is a cleaner, friendlier alternative to [asdf](https://asdf-vm.com/) that plugs into its plugin ecosystem with a highly minimalistic command surface and enjoyably better performance.

https://github.com/user-attachments/assets/105fcaf9-4ce4-4f55-9e16-cbe6014a9115

## Quick start

```sh
curl -fsSL https://snehil-shah.github.io/zxcv/install.sh | sh
```

Then in any project with a `.tool-versions`:

```sh
zxcv install
```

That's it. Find the full documentation and usage instructions [here](https://snehil-shah.github.io/zxcv/), or use the `zxcv --help` command.

## Why?

- **Dead simple**: Handful of self-explanatory commands.
- **No plugins**: No manual plugin management, we do it all for you.
- **Faster installs**: Quick setups so you can have your tools ready ASAP.
- **Cleanest DX**: See it yourself!

Tools like [mise](https://github.com/jdx/mise) have grown into a full-fledged build system, so if you wish for a simple, quick, no-config tool-versions manager, you would love this.
